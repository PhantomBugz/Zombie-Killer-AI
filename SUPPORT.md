# Support

Zombie Killer is community-maintained alpha software supplied without warranty.

## Where to ask

- Reproducible defect: use the [bug report](.github/ISSUE_TEMPLATE/bug.yml).
- False positive or false negative: use the [detection report](.github/ISSUE_TEMPLATE/detection.yml).
- Proposed capability: use the [feature request](.github/ISSUE_TEMPLATE/feature.yml).
- Security vulnerability: use the private path in [SECURITY.md](SECURITY.md), never a public issue.

Before filing, run `uv run zk doctor`, record the release and operating system, and reproduce with synthetic data. Do not paste raw diagnostics until you have reviewed them. Remove usernames, paths, PIDs that identify unrelated applications, memory contents, prompts, credentials, and provider responses.

Maintainers cannot recover deleted data, unlock provider accounts, reverse blockchain transfers, provide tax advice, or guarantee support response times. Optional donations do not buy support or priority.
