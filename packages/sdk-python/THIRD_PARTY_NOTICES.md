# Zombie Killer Python SDK Third-Party Notices

This file applies only to the Zombie Killer Python SDK wheel and source distribution. The SDK declares no third-party runtime dependencies and uses only the Python standard library. Its archives contain project Python source, package metadata, and the package-local `LICENSE`, `NOTICE`, and `THIRD_PARTY_NOTICES.md` files; third-party runtime code is not bundled.

Build and test tools are not bundled in the wheel. They remain governed by their own metadata and legal files when installed in a development environment. This package notice is not a dependency or license inventory for a development environment or for any application that imports the SDK.

The engine, desktop application, native sidecar, and interface assets are separate artifacts with their own dependency and legal review.
